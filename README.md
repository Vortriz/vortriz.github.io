# Personal Portfolio Website

This is a personal portfolio website built with Astro.

## Project Setup

1. **General dependencies**:

   ```bash
   nix develop
   ```

2. **Install dependencies**:

   ```bash
   deno install
   ```

3. **Run the development server**:

   ```bash
   deno run dev
   ```

4. **Build for production**:
   ```bash
   deno run build
   ```
